# Local inD data

Place the registered inD files here. This directory is excluded from Git so the
dataset and background images are not uploaded.

Expected files for the default recording:

- `18_tracks_del_vru_static_maneuver.csv`
- `inD_backgroud_images/18_background.png`

Get the dataset from the official [inD dataset site](https://levelxdata.com/ind-dataset/)
and follow its terms. The simulation also needs the hand-drawn map mask at
`map/drivable_mask_images/18_mask.png`.
